## LANTRO UI v2.0 – THE AVENGER

Thank you for using Lantro UI v2.0 (The Avenger Edition)

This is a modern, optimized, and performance-focused Blogger theme designed for speed, SEO, and user experience.

---

## 📦 FILE STRUCTURE

Theme/

* theme-lantro-ui-2026-avenger.xml  → Main Blogger Theme File
* theme-lantro-ui-2026-avenger.txt  → Backup / Editable Version

Pages/

* contact.txt  → Contact Page Code
* sitemap.txt  → Sitemap Page Code

---

## ⚙️ INSTALLATION GUIDE

1. Go to Blogger Dashboard
2. Navigate to Theme
3. Click on "Restore / Upload"
4. Upload the XML file:
   theme-lantro-ui-avenger-2026.xml

---

## 📄 SETUP PAGES

Contact Page:

* Create a new page in Blogger
* Switch to HTML view
* Paste code from contact.txt
* Publish

Sitemap Page:

* Create a new page
* Switch to HTML view
* Paste code from sitemap.txt
* Publish

## ⚡ RECOMMENDED SETTINGS

* Enable HTTPS
* Use Cloudflare (Recommended)
* Enable Brotli Compression
* Optimize images before upload
* Avoid too many external scripts

---

## ⚠️ IMPORTANT NOTES

* Always keep a backup before editing theme
* Use the .txt file for safe customization
* Avoid heavy scripts to maintain speed (Recommend not to use external CSS or JS)
